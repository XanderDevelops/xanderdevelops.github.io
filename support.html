How to get help

  1. Create your account or log in.
  2. Open the Posts tab and choose the project.
  3. Choose post type: Support Thread or Blog Post.
  4. Write a clear title and detailed message.
  5. Users can comment after they log in.

Bug report instructions

  • Add exact steps to reproduce.
  • Share expected result vs actual result.
  • Include browser/device/app version if possible.
  • Paste exact error messages if available.
  • Mark urgent issues with URGENT in the title.

FAQ

Do I need an account to post?

Yes. Create an account or log in to publish posts and comments. You can still browse posts without logging in.

Where should I report bugs?

Create a Support Thread, pick the matching project, and include steps, expected result, and actual result.

Can I open this page for one specific app?

Yes. Use links like support.html?app=MedFile to open the board with that app preselected.
